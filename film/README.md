# 让界面，有一点真实 / A little dimension

20 秒知识短片 · 1920×1080 · 60fps · H.264 + AAC。

五种同类 **3D 旋转、翻面与开合交互**。每种都有场景、可复用 AI 提示词与指针操作演示；延续黑色 Bento 布局。无旁白，含原创配乐与音效。全部 3D 对象由 Three.js 程序建模，字幕与布局由 Canvas 合成。

## 五种控件

|控件|场景|片中提示词|
|---|---|---|
|开合笔记本|设备展示|做开合笔记本，沿铰链转动，打开亮屏。|
|文字方块|品牌文案|做文字方块，逐面旋转，当前面高亮。|
|旋转罐体|商品预览|做旋转罐体，拖动转向，点击开罐。|
|百叶翻页|作品轮播|做百叶翻页，条带错峰，翻面换图。|
|滚筒选时|预约选时|做滚筒选时，拖动滚动，松手吸附。|

片尾：**场景 + 动作 + 反馈。让复杂操作，变得凭直觉。**

## 可复用组件提示词

### 01 / 开合笔记本
为设备展示页制作可拖动的 3D 笔记本。用真正的铰链父节点旋转屏幕，限制开合角度。向上拖动或点击打开；打开到阈值后，屏幕依次点亮并显示演示桌面。合上时熄屏。拖动位置、角度与亮屏状态一致，提供键盘操作与减少动态替代。

### 02 / 文字方块
为品牌关键词轮播制作 3D 文字方块。每一面显示一个关键词，点击下一面时沿水平轴旋转 90 度；当前面明亮，侧面随角度变暗。底部指示器同步更新，翻到背面后文字仍保持正确阅读方向。支持前后切换、键盘和暂停自动播放。

### 03 / 旋转罐体
为商品预览制作可旋转的 3D 饮料罐。标签真实包裹圆柱，随透视自然缩窄；横向拖动改变朝向，松手后平滑减速。提供开罐按钮，拉环抬起并出现短暂气泡反馈。商品文字为明确标识的示例内容，支持触屏与键盘旋转。

### 04 / 百叶翻页
为作品轮播制作八片纵向百叶的 3D 翻页。每片正面显示当前图的一条，背面显示下一图对应的一条；点击下一张时按顺序错峰旋转，拼成完整新图，边缘有厚度和阴影。前后切换方向应一致，防止快速点击造成状态错乱，并提供减少动态切换。

### 05 / 滚筒选时
为预约或闹钟界面制作 3D 滚筒时间选择器。时段、小时、分钟按圆柱曲面排列，中线显示当前值，上下数字随曲面倾斜并变暗。拖动时跟手，松开后吸附最近刻度；选中值和顶部时间同步。支持键盘增减、触屏和明确的选中语义。

## 整片制作提示词

```text
制作 20 秒、1920×1080、60fps 的 3D 控件知识短片。
五项为开合笔记本、文字方块、旋转饮料罐、百叶翻页、滚筒选时。
每项显示使用场景、两行可复用 AI 提示词、明确的指针动作和操作结果。
延续黑色 Bento 分区、Inter 大标题、中文短句和橙粉紫标题渐变。
五项在片头和片尾同时编号展示，讲到的主体放大，其他收为缩略卡。
用 Three.js 真实几何表现铰链、立方体、柱面标签、双面百叶和数字滚筒。
模型用工作室灯光、接触阴影和克制的金属/哑光材质，保证转到背面后文字不倒置。
以 Canvas 合成字幕，暴露 window.draw(t)；画面完全由 t 决定，字体加载后创建文字纹理。
分镜：0–2 总览、2–5 笔记本、5–8 方块、8–11 罐体、11–14 百叶、14–17 滚筒、17–20 总结。
结尾总结「场景 + 动作 + 反馈」，落句「让复杂操作，变得凭直觉」。
Python 合成 120 BPM、2/4 拍配乐；章节在小节线上；交互音与动作落点对齐，完整乐句淡出。
先检查九帧并至少修改两轮，再逐帧导出 JPG，FFmpeg 编码 H.264 yuv420p + AAC、faststart。
检查实际 MP4 播放、拖动和音频峰值，交付视频、总览、源码、提示词和步骤。
```

## 制作步骤与复现

1. 从下方源站核实五种交互，写场景、短提示词和带时间码分镜，见 [treatment.md](treatment.md)。源站不同控件可能采用 CSS 或 Canvas，本片独立用 Three.js 重绘机制。
2. 安装 Node.js、Python 3/numpy、Chrome 和 FFmpeg。执行 `npm install`。
3. `scene3d.js` 创建几何、字体纹理、材质和光照；`index.html` 负责 Bento 布局、字幕、时间驱动与操作指针。字体和库全部在本地。
4. `python3 make_audio.py` 生成 20 秒原创配乐和音效：120 BPM、2/4 拍、20 小节，18 秒终止和弦后留尾音。
5. `npm run stills` 导出九个关键时刻至 `previews/`，检查几何、文字正反、曝光和遮挡。Chrome 默认使用 macOS 安装路径，其他系统通过 `CHROME_PATH` 指定。
6. `npm run render` 逐帧调用 `draw(i/60)`，生成 1,200 张 JPG 到 `frames/`。浏览器需支持 WebGL。
7. `sh encode.sh` 合成 `spatial-microinteractions-20s.mp4`，设置 H.264 Main/yuv420p、AAC、响度处理、faststart、每秒关键帧。
8. 从最终 MP4 抽帧核对，完整播放并跳转。验收记录见 [QA.md](QA.md)。
9. 可使用 huashu-motion 的 `om studio . --no-open` 打开时间轴工作室；`om check .` 检查确定性，`om qa .` 检查突帧与节奏。

`index.html` 是影片合成，不是响应真实拖动的生产组件页面；操作由时间轴演示。完整组件提示词用于后续制作交互网页。
